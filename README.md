# Simple Weather App
A simple weather application built with React that fetches real-time weather data using the OpenWeatherMap API.
Users can search for any city to view its current temperature, condition, and country. The app also includes a loading screen while fetching data and displays an error message if the city is invalid.

# Features
Search weather by city name

Displays:

City & Country

Current Temperature (°C)

Weather Condition

Weather Icon

Loading GIF while fetching data

Error handling for invalid city names (No data found)

Clean and responsive UI

# Tech Stack
React (Frontend framework)

OpenWeatherMap API (Weather data provider)

CSS (Styling)
